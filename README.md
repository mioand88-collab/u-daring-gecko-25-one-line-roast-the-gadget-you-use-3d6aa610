# One-Line Roast: The Gadget You Use Every Day

My phone charger has reached the stage where it only works when the cable is bent into a yoga pose — and one wrong breath kills the charge. It is a roast of the most everyday gadget of all, the thing I plug in every night and curse every morning, because the cable has frayed just enough that charging is no longer a given but a balancing act I have to perform perfectly still, like defusing a bomb with my own phone.

## How to run

```sh
npx tsx main.ts
```

This writes the roast line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
